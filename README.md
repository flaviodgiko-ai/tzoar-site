# TZÔAR — Site institucional V2

## Visualizar
Abra `index.html` no navegador. A animação quadrada fica na coluna direita sobre fundo preto puro; o lado esquerdo mistura preto com azul-universo.

## Publicar gratuitamente no Cloudflare Pages
Envie o conteúdo desta pasta como Direct Upload, mantendo `index.html` na raiz.

## Arquivos
- `assets/tzoar-animacao.mp4`: vídeo quadrado fornecido pelo usuário (6,1 segundos).
- `assets/tzoar-logo-original.png`: logomarca estática.
- `assets/style.css`: layout responsivo e fundo espacial.

## Antes de publicar
Configure o contato real no lugar do e-mail de exemplo. O site não contém ainda um agente de IA funcional.
